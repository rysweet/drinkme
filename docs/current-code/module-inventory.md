# Module inventory

| Module | Role |
| --- | --- |
| `core` | Aggregator for core Alice modules. |
| `core/util` | Shared utilities and math primitives. |
| `core/ast` | Abstract syntax tree and project/version model. |
| `core/croquet` | UI/application framework pieces used by the IDE. |
| `core/i18n` | Internationalization support. |
| `core/ide` | Main Alice IDE shell, document frame, stage IDE behavior, story editor integration. |
| `core/image-editor` | Image editing support. |
| `core/issue-reporting` | Bug/issue reporting support. |
| `core/resources` | Application resources and platform native distribution assembly. |
| `core/scenegraph` | Scenegraph representation. |
| `core/glrender` | JOGL/OpenGL rendering integration. |
| `core/story-api-migration` | Story API migration logic. |
| `core/story-api` | Public story/programming API. |
| `core/model-loading` | Model import/export/loading pipeline. |
| `core/tweedle` | Tweedle language parser and model integration. |
| `core/models` | Gallery model module. |
| `external/collada` | COLLADA Java library module. |
| `external/collada-schema-1-4-1` | COLLADA schema support. |
| `external/wrapped-flow-layout` | Wrapped flow layout dependency. |
| `alice-ide` | Runnable Alice 3 desktop IDE entrypoint. |
| `netbeans` | Alice NetBeans plugin. |
| `core-nonfree/*` | Restricted/nonfree resource overlays; not part of the default root module list. |
